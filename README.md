# Virtual OS Simulator

A Python-based virtual operating system simulator built to demonstrate core Object-Oriented Programming principles and operating system concepts.

## 🚀 Features

- Process lifecycle modeling
- Custom scheduler
- FCFS and Round Robin strategies
- File system abstraction
- Kernel simulation
- Command interface

## 🧠 OOP Concepts Demonstrated

- Abstraction
- Encapsulation
- Inheritance
- Polymorphism
- Strategy Design Pattern

## 📂 Project Structure

- process.py
- scheduler.py
- kernel.py
- file_system.py
- commands.py

## 🛠 Tech Stack

- Python 3
- Pure OOP Design
